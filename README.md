# The Protein Point

Official website for **The Protein Point**, a healthy food brand based in Nanded, Maharashtra.

The website showcases the brand, menu, food offerings, location, and Instagram presence in a modern, responsive and mobile-first design.

## 🌱 About

The Protein Point focuses on fresh, tasty and protein-oriented food options designed for a healthy and convenient lifestyle.

## ✨ Features

- Modern responsive design
- Mobile-first layout
- Brand-focused visual identity
- Digital food menu
- Product/menu cards with pricing
- About The Protein Point section
- Instagram QR code
- Instagram profile integration
- Location information
- Google Maps directions
- 7-stamp rewards preview
- Responsive navigation
- Optimized for fast loading
- Vercel deployment ready
